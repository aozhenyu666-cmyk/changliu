# 长流 · 真机验证清单（P0）

> 目的：确认融合后的 `com.changliu.app` 能装、能拦、能连模型、key 确实加密。
> 每条都给了"怎么做"和"看什么算过"。打勾前请真的在手机上跑一遍，别只看编译过。

## 0. 装机

- [ ] CI 产物 `changliu-debug-apk` 解压得到 `app-debug.apk`；或本地 `gradlew :app:assembleDebug`。
- [ ] `adb install -r app-debug.apk` 成功（签名固定，可覆盖旧版）。
- [ ] 桌面图标名字是「长流」，包名 `com.changliu.app`（`adb shell pm list packages | grep changliu`）。
- [ ] 旧版思维驾驶员（`com.dshdriver.app`）若装着，是独立两个 App，互不覆盖——确认这是预期（数据不互通）。

## 1. 权限与保活

- [ ] 首页「要的权限」里：无障碍开关打开后，`adb shell settings get secure enabled_accessibility_services` 含 `com.changliu.app/...WatchService`。
- [ ] 「使用情况访问」打开（兜底前台判断）。
- [ ] 电池优化白名单 / 自启动按机型打开。
- [ ] 杀掉 App 进程后，守护/看门狗能把它拉回来（观察通知栏常驻通知是否恢复）。
- [ ] 重启手机后，无障碍仍在（设备所有者或 WRITE_SECURE_SETTINGS 写回生效）。

## 2. 拦截门（强制全屏页面）

- [ ] 首页「拦截娱乐 App」→ 开 → 选一个娱乐 App（如 B 站）。
- [ ] 打开那个 App：**整页**切到拦截门（不是小弹窗），最近任务里划不掉（excludeFromRecents）。
- [ ] 随便打几个字（无依据）→ 提交 → 不放行，给出驳回理由。
- [ ] 写一句带因果/原文/数字的依据（≥最少字数）→ 提交 → 放行并打开目标 App。
- [ ] 放行期内重开同一个 App 不再拦；到期后再开会再拦，且当天重复放行时长递减。
- [ ] 「不打开了」/返回键 → 回桌面，草稿清掉，下次开门是新题。
- [ ] 答题中途切走再回来：原题和已输入内容还在（gate_session.json 恢复）。
- [ ] 每天放行总额度用尽后，答对也不放行（nightBan/额度逻辑）。

## 3. 直连大模型（网关）

- [ ] 首页「直连大模型」→ 开 → 填网关地址、主模型 `gemini-4-argon`、轻模型、API key → 保存。
- [ ] 「测试连接」→ toast 显示「网关正常：收到」（或模型实际回复）。
- [ ] 拦截门出题时，题目来源标记为 `llm`（`adb shell run-as com.changliu.app cat files/driver/sessions/gate.jsonl` 里 `question.source=llm`），且不是模板那句。
- [ ] 关掉网关或填错 key → 拦截门自动回落模板题，不崩、不卡死。
- [ ] 陪练中（开始一次陪练）追问卡由网关出题；限速/逃逸时出的是 ab/两词原子动作。

## 4. key 加密（安全约束，必查）

- [ ] `adb shell run-as com.changliu.app cat files/driver/llm.json`：**只有 `sealedKey` 密文，没有任何明文 key**，也没有 `apiKey` 字段。
- [ ] 推进日志 `sessions/*.jsonl`、gate.jsonl 里 grep 不到 key 明文。
- [ ] `adb logcat | grep -i sk-` 跑一遍流程，日志里不出现 key。
- [ ] 「清除 key」后 llm.json 里 `sealedKey` 消失，大脑回落模板。
- [ ] 仓库全文 grep 不到真实 key（`grep -rn "sk-WPoA" .` 应为空）。

## 5. 回归（别把原有能力弄坏）

- [ ] `gradlew :core:test` 全绿（状态机/水位/骰子/去重/议程/拦截判卷）。
- [ ] 配对了大肥鱼（DSH Go）且网关关闭时，仍走大肥鱼出题（Brains.best 回落顺序正确）。
- [ ] 自我察觉/监督模式开关、截图仅存本机 7 天、不上传——与改版前一致。

## 已知未做（P0 之后）

- 总控/一手的功能尚未真正并入（当前基座是思维驾驶员 + 直连网关）；融合是后续阶段。
- 情绪引擎（暖/调侃/冷/严/暴躁 + 随机突变）只在 system prompt 里给了基调，独立的加权 mood 状态机未落地。
- 宪章/信用分/冷静期门未落地。
- 数据迁移（旧 App → 长流）未做。
