长流 0.7.0-fusion（调试版）安装说明
====================================

一、安装
1. 把 changliu-0.7.0-fusion-debug.apk 传到手机（数据线 / 微信文件传输 / 网盘都行）。
2. 点开 APK，允许「安装未知应用」后安装。
3. 可以覆盖安装旧版长流；卸载会清掉本机数据。
4. 系统要求：Android 8.0（API 26）及以上。

二、首次打开后要开的权限
1. 系统设置 → 无障碍 → 已下载的应用 → 长流 → 打开。
   （这是拦截、主动搭话、五态估计的核心，关着就完全不工作。）
2. 悬浮窗：设置 → 应用 → 长流 → 显示在其他应用上层（主动搭话小卡用；没有则退化为通知）。
3. 通知：允许通知（常驻状态、拦截提醒）。
4. 电池：不限制 / 允许后台活动（国产 ROM 还要开「自启动」「后台弹出界面」）。
5. 使用情况访问（可选）：无障碍掉线时的兜底判断。

三、注意
- 覆盖安装 APK 后，系统会把无障碍从已启用列表移除，需要重新打开一次；这是 Android 的行为。
- API key 只在 App 设置页里填，用系统密钥库加密存本机，不会写进安装包或日志。
- 这是调试签名包，不能上架应用商店；仅供本机使用。
- 许可证：GPL-3.0（融合了驾驶员底座、一手、总控）。

四、入口
- 桌面图标「长流」→ 首页 / 训练（一手）/ 四部（总控）/ 我的。
- 「我的 → 长流引擎」可以看五态、语气、它记得什么、语音搭话开关。
- 「我的 → 权限」可以逐项打开无障碍、悬浮窗、电池、使用情况。
